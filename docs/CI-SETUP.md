# Сборка неподписанного .ipa через GitHub Actions (с Windows)

Сценарий: CI собирает **неподписанный** .ipa, подпись выполняется вручную
на iPhone через ESign вашим .p12 + .mobileprovision. Доступ к developer.apple.com
и Xcode не требуется. Секреты в репозитории тоже не нужны.

## Что делает workflow

1. Генерирует Xcode-проект из `ios/project.yml` через XcodeGen.
2. Собирает Release-сборку с отключённой подписью
   (`CODE_SIGNING_ALLOWED=NO`).
3. Упаковывает полученный `.app` в структуру `Payload/` и зипует в `.ipa`.
4. Выкладывает `PotRemote-unsigned.ipa` как артефакт сборки.

## Запуск

1. Залить проект в репозиторий на GitHub.
2. Пуш в `main` — сборка стартует автоматически.
   (или вкладка Actions → Build Unsigned IPA → Run workflow)
3. Actions → последний запуск → блок Artifacts → скачать
   `PotRemote-unsigned-ipa` (внутри zip лежит .ipa).

Никаких правок `project.yml` под подпись делать не нужно — bundle ID
подставится из вашего профиля при подписи в ESign.

## Подпись на телефоне через ESign

1. Перенесите на iPhone три файла: `PotRemote-unsigned.ipa`, ваш `.p12`
   и `.mobileprovision` (через Файлы, AirDrop с ПК невозможен — используйте
   облако/кабель/локальный сервер).
2. В ESign импортируйте сертификат: раздел с сертификатами → добавить →
   укажите `.p12` (введите его пароль) и `.mobileprovision`.
3. Импортируйте `.ipa` в ESign (Files → выбрать файл, либо «Открыть в ESign»).
4. Нажмите на приложении → Sign → выберите импортированный сертификат → Sign.
5. После подписи — Install. iOS поставит приложение.
6. Настройки → Основные → VPN и управление устройством → доверьтесь профилю.

## Важно

- .ipa неподписанный — установить его напрямую (Sideloadly/iTunes) без
  предварительной подписи не выйдет, только через подпись в ESign (или AltStore).
- Срок жизни подписи зависит от вашего сертификата от посредника
  (обычно год для Enterprise/платного аккаунта).
- Если ESign ругается на bundle ID — в его настройках подписи включите
  опцию замены bundle ID на тот, что зашит в вашем .mobileprovision.
